# Chrome Extension for Productivity 🚀

A Chrome extension that tracks website usage and provides productivity insights through a clean and simple dashboard.

## ✨ Features

* ⏱️ Tracks time spent on different websites
* 📊 Displays usage data in an easy-to-understand dashboard
* 🧠 Helps users understand browsing habits and improve productivity
* ⚡ Runs efficiently in the background

## 🛠️ Tech Stack

* JavaScript
* HTML
* Chrome Extension APIs (Manifest V3)

## 📂 Project Structure

* `manifest.json` – Extension configuration
* `background.js` – Tracks website activity
* `popup.html` & `popup.js` – Extension popup UI
* `dashboard.html` & `dashboard.js` – Usage analytics dashboard

## 🚀 How to Use

1. Clone or download this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the project folder
5. Start browsing and view usage stats in the dashboard
